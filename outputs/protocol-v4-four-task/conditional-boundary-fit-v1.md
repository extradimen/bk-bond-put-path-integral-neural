# 状态条件继续持有价值 B/C/D 拟合 v1 事前冻结

使用新 SHA-256 固定的训练/验证状态条件样本，仅覆盖 F-B/T-B，不读取测试组。B 直接拟合继续持有价值，C 拟合相对条件 GTFK 基线 A 的残差，D 拟合相对条件粗 PDE 基线 Dbase 的残差。每格每法两宽度 32/64、两随机种子 11/29、2 隐层、学习率 0.001，最多 300 epoch、batch 256、patience 30；共 24 个候选。每格每法按**真实验证继续持有价值 MAE** 最低选一模型，平局按模型文件名固定规则。

验证目标 MAE <= 0.002 事前固定，未达标保留失败与全部原始候选，不在此阶段调门槛。该目标只是小样本方法可行性筛查；真实测试根拓扑、根位置以及完整四格和全分布导数仍须另阶段事前冻结后评估。训练样本组数 16/格并非四格主价格研究的 4096/格正式预算；此阶段结论不得替代该主研究。

实验需不可变快照、同项目 SHA-256 数据/环境、全局 resources/preflight/experimentctl launch、节点 OS child wait 与校验回传。
