# A 与粗 PDE 的真实行权边界探索性试跑 v1：事前冻结

2026-10-25。本补充研究不修改四格价格主比较或原边界 23/32 资格门槛。现有 B/C/D 网络只输入 t=0 合约参数、输出 t=0 价格，不产生行权日状态条件继续持有价值；因此本试跑只比较确实定义该曲线的 A（GTFK）和 Dbase（粗 PDE），不把 B/C/D 价格预测冒充行权根。

从已归档边界拓扑诊断中选 F-B 1、13 和 T-B 3、10 的中间执行价，共四个已观察测试格-组，明确归类为探索性数值试跑，不作事前盲测推断。数据文件和 SHA-256、全部数值设置、执行顺序、总量 4/4 均冻结于 `configs/put-method-boundary-pilot-v1.json`。A 使用 401/32/32 与 801/48/48 两档；Dbase 使用 201 点、每年 100 步；参考 PDE 使用 1601/100 和 3201/200 两档；独立 OU 分裂传播使用 1601/100/24。每一档沿各行权日记录根数、全部根位置、gap 范围和时间。只在同日两曲线均恰有一根时计算短利率根位置绝对差，不为多根、无根或拓扑冲突臆造数值。

预定数值资格：细 PDE 与粗 PDE 参考档的根差、细 PDE 与 OU 独立传播的根差，以及 A 两档之间的根差均须不超过 1e-4（短利率绝对单位）且根数一致，才讨论 A/Dbase 相对于细 PDE 的根误差；不合格的格-组直接记录为未认证。该试跑只核查可实现性和误差尺度；若有资格通过，后续完整边界样本和正式门槛须另行冻结，不用本次四组作确认性结论。

运行须经项目部署器、全局 resources/preflight/experimentctl、不可变项目快照、同项目 SHA-256 物料和环境收据、节点 OS child wait 与校验回传。所有失败保留。
