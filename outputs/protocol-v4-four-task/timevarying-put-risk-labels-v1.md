# 时变 T-E/T-B 风险导数测试子集标签 v1 冻结

运行前冻结于 2026-10-23。四格价格主结果已观察，因此本阶段是 E3/E4 探索性风险结构补充，不构成新的确认性方法优劣检验。使用 v8 已认证测试数据 SHA-256 `b1db5c8042c8ac2d6090656add4d16b089d35f0403ac90e41c07d0b833da79ce`，T-E/T-B 各取组号 0–127 的中间执行价，共 256 格-组；组号、执行价和参数坐标在运行前固定。v1 的两训练组和 v2 的 32 验证组不并入本阶段。

沿用已通过 32/32 验证组的七坐标中心差分及 PDE 3201/6401 点空间轴、全/半步长轴，每年 400 步；`sigma1`、`log(r0)` 另查每年 800 步时间轴和 9601 点/1.5 倍截断域轴。逐组每坐标有定义的绝对变化均须不超过 1e-4，七坐标全部通过才计为认证组。失败账本保留，不删组或调门槛。结果只作为此测试子集中间执行价的参考导数，可用于后续探索性风险结构和方法导数误差分析；时间/域轴代表性范围必须单独披露。

固定 campus-3090-2，单节点 CPU，至少 16 GiB 内存，最长 180 分钟。必须使用项目部署器完成不可变快照、同项目 SHA-256 物料及环境收据、全局 resources/preflight/experimentctl launch；逐组 JSONL 记录进度，终态以节点 OS child wait 与 SHA-256 回传为准。模型导数计算和统计比较须另行冻结，不在本阶段混做。
