# 状态条件继续持有标签质量与计时 v1：事前冻结

四组已观察测试合约的条件继续持有参考试跑通过，但不能据此冻结新状态条件 B/C/D 模型训练。此阶段只在原正式数据的训练/验证划分中评估数值标签质量、根拓扑比例与每组成本，不访问测试组，也不拟合任何网络。冻结 F-B/T-B 两格、train/val 各前 8 个组的中间执行价，合计 32 格-划分-组；样本按原组级划分隔离。

每组全部三个行权日用 1601 点/每年 200 步与 3201 点/每年 400 步细化 PDE 条件继续持有曲线，以 3201 点/每年 400 步/24 阶精确 OU 分裂独立复核。预先固定 33 个内部状态点；PDE 档间与 PDE/OU 继续持有最大绝对差各不超过 1e-4，最后行权日继续持有为零，记为标签通过。单根拓扑与短利率根差 1e-4 单独记录，失败不剔除或放宽；标签通过不要求每组都有边界根，因为全行权/全等待也可提供有效值标签。逐组时间和失败率用于下一轮正式样本、预算、训练容量与测试边界门槛事前冻结，不能并入正式测试结论。

代码与合成常参数退化、PDE/OU 数学接口先完成普通测试。证据阶段须经项目部署器、全局 resources/preflight/experimentctl launch、不可变快照、同项目 SHA-256 物料及环境收据、节点 OS child wait 与校验回传。原 23/32 边界门槛及所有失败保持不变。
