# F-E/F-B PDE 误差匹配与成本扫描 v1：运行前冻结

本阶段是固定参数两格的 E2 补充分析。既有两格测试结果已经查看，因此本阶段及其后续推断均标记为探索性；不能将验证集选出的配置声称为事前确认性结果。

输入只用 `fixed-put-formal-recovery-v2` 的 SHA-256 固定数据包中 F-E/F-B 验证集每格组 0–127，各组三执行价，共 384 个合约/格。参考价格、A 价格和原 Dbase 都从同一数据包读取。扫描 PDE 空间点数/每年时间步配对为 (51,25)、(101,50)、(201,100)、(401,200)、(801,400)，每组完整三执行价计时。201/100 必须在每例以 1e-9 复现冻结的 Dbase，若不符则阶段失败。

按每格验证集组均绝对误差计算 A 与各 PDE 配置的价格 MAE。E2 候选选择规则：取与 A 的验证 MAE 绝对差最小者；相同则取平均每组在线耗时更短者，再按空间点数排序。该规则仅选数值基线，不用测试价格。记录每档误差、每组三执行价耗时以及每例价格。12 个 CPU 工作者；项目部署器、全局资源预检和控制器启动；节点不可变快照、同项目物料/环境收据及 OS wait/校验回传均为证据条件。

此扫描不能单独证明 PDE 与 GTFK 算法族的速度优劣；网格同时改变空间与时间分辨率，完整独立轴前沿及 E2 残差网络训练须后续追加冻结。
