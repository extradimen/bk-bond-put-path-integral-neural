# 状态条件行权边界比较：设计草案，尚未冻结或运行

既有 B/C/D 网络输入仅定义 t=0 合约到 t=0 价格，不能从其输出求行权日的继续持有价值。A、Dbase 与独立 PDE/OU 的真实根比较已完成后验探索；若要将 B/C/D 纳入**真实局部边界**，需新增状态与行权日条件的继续持有价值模型。本草案不是原四格正式主比较，也未授权把旧 t=0 权重当作新模型。

候选任务对 F-B/T-B 分别在行权日 e1/e2 以合约参数、行权日、当前 log-rate 和执行价为输入，预测条件继续持有价值。参考标签来自细 PDE 的倒向递推；独立精确 OU 分裂传播要在预选合约和边界状态交叉核验根数与根位置。B 直接拟合继续持有价值，C 拟合相对 GTFK 条件基线的残差，D 拟合相对粗 PDE 条件基线的残差；在线成本包括数值基线。最后行权日的继续持有价值恒为零，只作为数学退化检查，不拿来训练可学习的边界。

必须先实现并单元验证条件曲线、输入编码、参考数值稳定与根搜索；再基于训练/验证组的先验计时和质量试跑冻结样本、容量、预算、方法比较、根拓扑/精度门槛及测试组。所有组级划分必须沿用原数据，训练组不得接触测试组 PDE 曲线或根。初始小样本仅检验可行性，不得称为四格全分布边界认证；任何数值失败和训练失败原样保留。证据运行一律按项目部署器及全局实验控制器要求执行。
