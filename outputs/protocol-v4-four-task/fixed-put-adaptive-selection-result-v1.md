# 固定参数 E6 条件选法：探索性结果

`fixed-put-adaptive-selection-v1` 在不可变源快照和 SHA-256 输入下运行，节点 OS child wait=0，结果校验回传。规则只在验证集训练，为单阈值或常数法；以下是 2048 组测试结果。神经候选是五种子预测均值，故与主实验的“五种子误差均值”数值不同。

| 格子 | 误差/秒权重 λ | 验证选择 | 测试 MAE | 平均在线秒/组三执行价 |
|---|---:|---|---:|---:|
| F-E | 0 | 全用 C | 1.7845e-7 | 0.3713 |
| F-E | 1e-7 | 全用 C | 1.7845e-7 | 0.3713 |
| F-E | 1e-5 | `log(a)≤-2.0354` 用 C，其余用 D | 1.4987e-6 | 0.0531 |
| F-B | 0 | `log(a)≤-0.4725` 用 C，其余用 D | 1.3235e-6 | 57.51 |
| F-B | 1e-7 | 全用 D | 3.4060e-6 | 0.0443 |
| F-B | 1e-5 | 全用 D | 3.4060e-6 | 0.0443 |

F-E 在较高耗时权重时，简单阈值比验证选择的全用 D 在测试中误差更低（1.499e-6 对 1.887e-6），但平均耗时约 0.0531 秒/组，高于全用 D 的约 0.0192 秒/组。F-B 在零成本权重下，混合规则比全用 C 的测试 MAE 1.6262e-6 更低，但需要平均约 57.5 秒/组，实用性弱。一旦计入很小的每秒误差权重，验证集就选择全用 D。

由于主测试结果已被查看，这只能说明验证集学到的简单规则在这批测试样本上的表现，不能视为新的预注册主发现。在线时间是相同实现计时的组合代理；五种子推断增量按五次计价，未重新实测整条路由的端到端延迟。详细规则、各方法次数和常数对照见 [summary.json](../../outputs/fixed-put-adaptive-selection-v1/results/summary.json)。
