# F-B 同误差级别 PDE 残差网络 E2 v1：运行前冻结

验证集 128 组网格扫描在已经观察过固定参数正式测试结果之后完成，故 E2 完全属于探索性复核。扫描 SHA-256 固定的结果按原规则选出 F-B 网格 101 点/每年 50 步；F-E 最接近 A 的网格仍是原 201/100，暂不重复训练 F-E。

使用原正式数据包，F-B 训练前 1024 组、完整 1024 组验证、测试前 512 组，各组三执行价。组划分和参考价不变。为新 Dmatch 逐例计算 101/50 基线，网络学习 `参考价−该基线`，五种子 11/23/37/53/71，固定容量 3 隐藏层×64、学习率 0.001；复用原 `MLP.fit` 早停、输入标准化和目标标准化。比较对象为原同一 1024 组预算/五种子/固定容量的 D 网络、A、Dbase，以及新 Dmatch 的未修正基线。所有模型测试于相同 512 组，不使用测试价选网格、容量、学习率或种子。汇报五种子平均 MAE、逐种子 MAE、95%分位与最大误差，并保留逐组三执行价计算记录。运行通过项目不可变部署、同项目 SHA-256 物料与环境、全局预检/launch、节点 OS child wait 及回传校验。

原测试价格此前已查看，不对该 512 组作新的确认性显著性检验。扫描和训练的多工作者成本不是隔离在线计时；E2 的目的仅是观察把 PDE 基线误差降/升到与 A 接近后，残差学习的表现是否改变。不得把这一步解读为两种数值方法族的普适速度排名。
