# 固定参数 E5 标签分辨率敏感性分析 v1（执行前冻结）

读取正式 F-E/F-B 测试 2048 组的原始 PDE 网格细化指标、正式价格标签、五种子调优 4096 预算预测，以及 A/Dbase 数值基线。均按每组三执行价先取平均绝对误差，再计算方法总体均值。对六个已冻结主要成对比较，报告：平均误差差与平均指标两倍之比，以及每组方法误差差绝对值不超过该组两倍指标的比例。另报告每方法组误差低于指标的比例。输入均锁定 SHA-256。

**解释边界**：原账本 `error_indicator` 是空间/时间/域网格变化的数值分辨率代理，不是严格的真实标签误差上界；`2 × indicator` 是启发式敏感性尺度，不能证明真实误差排序或重新解释正式 Holm 检验。主试验结果已查看，本项只分析结果对标签分辨率的脆弱性，不重选模型、不改动阈值或主假设。
