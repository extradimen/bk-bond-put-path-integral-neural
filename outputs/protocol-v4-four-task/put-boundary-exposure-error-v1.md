# 行权边界暴露与价格误差：事前冻结的探索性分析

使用既有 F-B/T-B 各前 16 个测试组的中间执行价、原边界拓扑分类、原冻结模型预测，不重新估计数值边界或训练网络。每格组号 0–15，共 32 格-组；固定 4096 训练组预算的 B/C/D 五种子，A 和 Dbase 为原数值基线。

仅两个提前行权日均为 `single_root_consistent` 的合约计算边界暴露；否则暴露标记为不可判定，保留并报告但不纳入近/远价格误差分层。对风险中性对数短利率 OU 过程，用各段精确高斯均值与方差计算每个行权日状态落在已认证行权根 `log(r*)±0.1` 内的概率，取两日最大值；概率至少 0.1 归为 near，其余为 far。比较相同中间执行价、同一测试组的 t=0 价格绝对误差；网络值先按五种子各自绝对误差平均。

这是见过主价格结果后的探索性暴露分层，仅测量 t=0 合约价格误差与未来状态靠近真实行权根概率的关系，不能称为神经网络在行权日状态上的局部继续持有价值或边界位置误差。原 23/32 冻结边界资格门槛不变，无法认证根的组不被丢失或强行归类。
