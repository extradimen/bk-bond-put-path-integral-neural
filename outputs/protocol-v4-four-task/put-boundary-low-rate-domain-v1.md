# T-B 2/12 低利率第二根的截断域敏感性：事前冻结

前阶段 `put-method-boundary-fail-diagnose-v1` 的 T-B 2 和 12 第二行权日，A 在两档分辨率下各有额外较低根，分别约 0.000201 与 0.000129；其宽度 1.0 状态网格的短利率下端约 0.000194 与 0.000124，因此额外根可能是低端截断效应。细 PDE 与独立 OU 各只看到一个高位根。该关系是运行本诊断前可见的结果，故本实验是后验机理诊断，不改写原 23/32 边界资格、32 组阶段的 90/96 合格数，或上一阶段的双根结论。

冻结两组中间执行价、各三个行权日，数据散列与设置在 `configs/put-boundary-low-rate-domain-v1.json`；总量 2/2 格-组。A 固定 4801 点、128/128 积分，状态域宽度 1.0、1.25、1.5；PDE 固定 6401 点/100 步、域宽度 1.0/1.5；独立 OU 固定 6401 点/100 步/24 阶、宽度 1.5。粗 PDE 201 点/100 步照录。逐档保存网格上下端短利率、根数、所有根、gap 极值和耗时。若低根随域扩张消失或贴着域下端移动，归为域敏感；若三域保持相近的物理短利率位置，记录为持续拓扑分歧；不能因更宽域的单根而事后称先前双根通过。参考 PDE 与 OU 在宽域的单根差 ≤1e-4 才将宽域参考视为本诊断内稳定。

项目部署器必须完成全局 resources/preflight/experimentctl launch、不可变源快照、同项目 SHA-256 物料/环境、OS child wait 及校验回传；失败原样保留。
