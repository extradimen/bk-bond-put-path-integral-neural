# F-B/T-B 真实行权边界数值预检 v1 冻结

在运行前冻结于 2026-10-23。为避免把 t=0 的百慕大—欧式价格差误称行权边界，按每个允许行权日的状态曲线直接计算 `max(K−P(e,T),0)−continuation(e,x)` 的零点；末次行权日只计算 `K−P(e,T)` 的零点，并分别标识“提前行权与继续持有”的边界和“末次收益折点”。F-B/T-B 各取其已认证正式测试集组号 0 的中间执行价，共 2 个格-组，不从价格误差结果挑组。固定数据 SHA-256 在配置中。输出每个行权日的全部零点（对数短率和短率）、有正内在价值且行权的网格节点数及 gap 范围；若无零点、多零点或边界触域，原样保留，不强制单边界叙述。

PDE 在状态网格 801/1601 点、每年 100 步比较空间轴；在 1601 点/每年 200 步比较时间轴；2401 点/域倍率 1.5 比较截断域。另以独立精确 OU 转移加贴现 Strang 分裂传播在 801 点、每年 100 步、Gauss-Hermite 16 阶复核。此预检只收集数值稳定性与拓扑，不预设边界误差通过门槛，不作为模型方法胜负或全测试集边界结论；后续须根据原始零点结构冻结扩展样本与可判定门槛。仅 F-B/T-B 具有提前行权边界，F-E/T-E 的末次收益折点不应混入该比较。

固定 campus-3090-2，单节点 CPU、至少 16 GiB、最长 60 分钟；项目部署器、不可变快照、同项目 SHA-256 物料/环境收据、全局 resources/preflight/experimentctl launch、节点 OS child wait 与校验回传必须完整。
