# F-E/F-B 导数标签补充实验：预运行冻结 v1

本阶段是已经看过固定参数看跌测试价格后的 E3/E4 探索性补充，不构成新的确认性检验，也不训练网络。输入仅为正式冻结数据 SHA-256 `f43b1488a839ebebe6c8300dedda7c050371bb3d0d6349928e8ebce3a3d100c9`。每格取训练前 256 组、验证前 128 组、测试前 128 组，每组三个执行价；组内价格和导数均不跨划分。

对 `log(a)`、`sigma`、`log(r0)`、`log(rbar)` 作中心差分，初始步长分别为 0.004、0.001、0.004、0.004，并各半步长复核。PDE 空间点数 3201 和 6401、时间密度均为每年 800 步；逐组、逐坐标、逐执行价的步长与空间差异最大值须不超过 `1e-4`。较细网格半步长值作为标签。完整逐组记录、失败列表和 CPU/墙钟开销保留；任何门槛失败则不生成可供训练的标签归档。预检 `fixed-put-risk-pilot-v3` 在旧 16 组上 16/16 通过；`fixed-put-risk-axes-v2` 在 8 组（含未参与修复的新组）上独立空间、时间、截断域和步长检查最大值依次约 2.91e-5、3.93e-8、5.40e-10、2.23e-5，均通过。逐组正式标签只验证空间与步长，时间和域只拥有代表性证据，不得声称已逐组认证。

固定使用 campus-3090-2、24 工作者、最多 4 小时。若运行中断，先审计全局租约、节点 PID 身份、日志和 OS child wait，不以终端状态重跑。经项目部署器、同项目 SHA-256 物料与环境收据、全局 resources/preflight/launch 启动；只在节点 OS wait 后校验回传结果。此结果的下游导数监督比较须另行冻结模型、损失权重、数据和成本预算。
