# 扩大状态条件标签的追加修复规则 v1（在 v2 结束前冻结）

原 `conditional-boundary-trainval-v2` 的 320 个格-划分-组和每组 1e-4 PDE/OU 标签资格门槛不变。v2 结束、OS child wait 与同项目 SHA-256 校验回传后，从其完整原始 `groups.jsonl` 精确取全部 `label_passed=false` 的组，不按模型表现或测试结果挑选。已合格组沿用原归档；仅失败组重新生成三个执行价、前两个行权日的状态条件标签和 A/Dbase 基线。

预先固定的加密序列为 PDE 1601 状态点/年 200 时间步/域宽 1.0，然后若未过再试 3201/400/1.0；每档均用独立 OU 分裂 3201/400/1.0/24 阶在所有训练状态核验，每条曲线最大绝对差必须 <=1e-4，且每组所有曲线都合格才能选用该档。保持原 33 个均匀内部状态、单根附近 log-rate 偏移 -0.1、-0.05、0、0.05、0.1、GTFK 801/32/32/1.0 与粗 PDE 201/100/1.0。任何组在两档都失败则保存失败账本、停止合并与拟合，不降低门槛。

修复阶段以 v2 原始归档及账本 SHA-256、同项目原始四格数据 SHA-256 为输入，严格检查冻结修复组集合等于原账本全部失败组，产出新的独立归档和 SHA-256；原归档及失败保持不动。不读取 test，不用模型验证选择数值档。所有证据计算经项目部署器、全局 resources/preflight/experimentctl launch、不可变快照、同项目物料/环境、节点 OS wait 和校验回传。后续训练及测试另行冻结。
