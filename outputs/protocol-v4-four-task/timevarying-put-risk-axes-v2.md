# 时变 T-E/T-B 风险导数扩展数值轴预检 v2

运行前冻结于 2026-10-23。v1 仅两格各一个训练组，七坐标的空间与步长轴通过；本 v2 不复用这些组，使用 v8 已认证验证集每格组号 0–15 的中间执行价，共 32 格-组。数据文件 SHA-256 为 `b1db5c8042c8ac2d6090656add4d16b089d35f0403ac90e41c07d0b833da79ce`。已见四格主价格比较，所以本阶段只作探索性导数数值认证，不作新的确认性模型优劣检验，也不把验证组当训练组。

七个参数坐标、中心差分步长、PDE 空间 3201/6401 点、每年 400 步、代表性 `sigma1` 和 `log(r0)` 的 800 步时间轴及 9601 点/1.5 倍截断域轴，全部保持 v1。每一差分步长、空间及有定义的时间/域变化绝对值须不超过 1e-4。逐组 JSONL 中必须有七坐标且所有检查通过；失败保留原值和组号，不能删组、放宽门槛或把 v1 作为本阶段计数。通过只证明这些 32 个中间执行价的导数数值稳定，不是全划分、全执行价认证。

固定 campus-3090-2，单节点 CPU、至少 16 GiB 内存，最长 90 分钟。脚本由项目部署器以不可变快照、同项目 SHA-256 物料和环境收据、全局 resources/preflight/experimentctl launch 执行；仅以节点 OS child wait 和 SHA-256 校验回传判定终态。
