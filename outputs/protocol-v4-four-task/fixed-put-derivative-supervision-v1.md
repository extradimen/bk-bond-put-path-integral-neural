# F-E/F-B 直接网络导数监督补充实验：运行前冻结

`fixed-put-risk-repair-v1` 的 20 个原失败组用 6401/12801 点空间网格重算后，全部通过原 `1e-4` 步长/空间差门槛；节点 OS child wait return_code=0、同项目 SHA-256 校验回传，最终标签归档 SHA-256 为 `608b6c64bd3b6ef9efc1a721b124e655f7372d9c61c8f73977ee090e8b248aba`。原 1,024 组标签、20 个失败及选择性重算账本保留。不同组采用通过门槛的 6401 或 12801 点标签；这是事后探索性风险分析，不能称统一误差上界的解析真值。

本阶段只识别 **B 直接网络** 加入导数监督的影响，不将其作为 A/C/D 方法族排名。每格使用相同冻结训练前 256 组、验证前 128 组和测试前 128 组；每组三个执行价。价格-only 和价格+导数两臂使用相同 3×64 tanh 网络、学习率 0.001、批量 256、最多 500 轮、早停 30 轮、同五个随机种子 11/23/37/53/71。价格+导数臂的导数损失权重 0.1，监督 `log(a)`、`sigma`、`log(r0)` 三坐标；`log(rbar)` 不监督，作为额外风险坐标检验。两臂都仅用**验证价格 MAE**选早停，测试价格和导数不参与训练/选择。输出逐种子价格 MAE、四坐标导数 MAE及训练耗时，以同种子成对比较，不修改四格价格主检验。

测试价格先前已查看，本阶段是探索性补充；如果导数监督改善风险但损害价格，必须如实并列报告。计算固定于 campus-3090-2、10 工作者，经项目部署器、同项目 SHA-256 物料/环境和全局 resources/preflight/launch 启动；节点 OS wait 与校验回传后才分析。
