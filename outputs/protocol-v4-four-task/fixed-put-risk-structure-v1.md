# F-E/F-B 风险结构 E3 补充分析 v1（执行前冻结）

仅用已有并通过原数值门槛的固定参数正式价格归档、风险导数归档中的测试前 128 组，共 3 个执行价。成对核对 F-E/F-B 的合同参数和组号；风险坐标为 `log(a)`、`sigma`、`log(r0)`、`log(rbar)`。按组内由低到高的三个执行价，以及这 128 组的波动率四分位，报告欧式/百慕大式价格、提前行权溢价 `FB-FE`、各参数敏感度和 `FB-FE` 敏感度差的均值、中位数、5/95 分位及负值比例。溢价低于 `-1e-6` 的例数单独列出，作为数值一致性检查。

这是已看过固定参数主结果之后冻结的**探索性描述**。不重新选择模型、门槛、分组或结果，也不把该 128 组的描述统计作为四格主要显著性检验。风险导数标签采用先前 20 组选择性空间加密后的认证版本；两种网格的差异需在解释中保留。
