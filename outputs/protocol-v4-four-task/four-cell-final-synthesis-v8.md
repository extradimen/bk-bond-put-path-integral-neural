# 四格债券看跌期权比较：扩大条件边界独立测试后的综合结算 v8

四格 t=0 看跌定价主研究和 E2–E6 分析结论沿用 `four-cell-final-synthesis-v7.md` 及其引用的 v6：C 在选定配置下价格平均 MAE 最低，B 在线最快而误差最大，C 的百慕大在线数值成本较高。旧欧式看涨数据不混入四格看跌。七坐标风险导数仍存在已认证的 A 方法反例，不能称全分布导数准确。

追加的状态与日期条件边界研究扩大为 F-B/T-B 各 train128/val32 组，原标签 16 组超出 1e-4 门槛，经事前冻结的两档规则重算后全部通过，原失败记录保留。72 项 B/C/D 候选拟合因节点重启在 54 项处中断：原运行退出码未知，54 个模型经同项目 SHA-256 归档，余 18 项另立续算阶段完成；新阶段 OS wait 0、72 个模型均校验回传。六个验证最优模型中仅 T-B B 未达 0.002 目标（MAE 0.002391）。

事前另定的新留出 test 128–191，每格 64 组，共 128 格-组、768 条早行权日曲线，已完整运行并取得 OS wait 0 和 SHA-256 回传。独立 PDE/OU 参考 753/768 条合格；B/C/D 的预定价值及根联合门槛分别通过 **165/768、454/768、239/768**。C 价值 MAE 很小（平均 0.00006095）且优于 B/D，但根拓扑仅匹配 484/768，故扩大数据和模型预算后仍不能认证其真实行权边界稳定准确。详细逐曲线证据见 `conditional-boundary-test-expanded-result-v1.md`。

由此，四格 t=0 价格和成本比较已完成；追加边界实证也已结算，但预定真实边界与七坐标导数的正面精度认证**未通过**。这属于明确的负结果，不是未运行完的实验。所有原门槛、失格参考、模型失败与节点中断证据均保留。当前项目无活动实验。
