# 固定参数 E6 条件选法补充 v1（执行前冻结）

只使用 F-E/F-B 正式验证集 1024 组来拟合每格最多一个分裂的决策规则；测试集 2048 组仅评估。候选为 A、B、C、Dbase、D。B/C/D 对五个正式选中种子的价格取均值；A/Dbase 用正式数值基线。组误差为三执行价平均绝对误差。规则输入只用定价前已知的合约参数（组内连续特征平均），不读取参考价格或任何方法输出作为在线决策输入。

对每个连续特征的预定 10% 至 90% 分位阈值搜索一层树，两叶各取使验证集 `MAE + λ × 在线秒数` 最小的方法；无分裂的全局常数法也参与。预定 `λ=0,1e-7,1e-5`（价格误差/秒）。在线秒数使用已有三执行价组计时中位数；五种子神经均值按五次神经增量计价，A/C 与 Dbase/D 共享基线开销按一次计价。报告验证选中规则、测试 MAE、方法使用次数、平均在线秒数及验证选中的常数法测试表现。

固定参数主要测试结果已被查看，此项为探索性选法演示，不能成为新的主要显著性检验。原在线计时是实现级代理，不能精确代替生产服务延迟；方法调用成本比较需同样的硬件和批量条件。
