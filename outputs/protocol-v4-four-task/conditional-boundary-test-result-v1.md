# 新状态条件 B/C/D 真实行权边界留出测试 v1：结果

预冻结的 F-B/T-B 各 16 个测试组（32/32 格-组）、每组三执行价及前两个行权日共 192 条曲线完成。campus-3090-2 的 worker/child PID、boot/start/cwd/command 身份与 OS child wait return_code=0 相符；`boundaries.jsonl` 和 `summary.json` 经同项目 SHA-256 校验回传。模型均为新状态/日期条件网络，不使用原 t=0 价格权重。

独立细 PDE 与精确 OU 分裂参考在 191/192 条日期曲线上通过事前拓扑、价值和根位置资格。余一条为 T-B 测试组 37、最低执行价、第二行权日：两法均单根，但 513 状态上的继续持有价值最大差 1.58055e-4，超过原 1e-4 门槛；不将其作为网络通过项。按事前联合门槛（价值 MAE <=0.002、预测根数正确、单根短利率根误差 <=0.001），B/C/D 分别通过 0/114/101 条（分母固定为全部 192 条，包含参考不合格项）。按格分别为 F-B：B 0、C 63、D 63 / 96；T-B：B 0、C 51、D 38 / 96。

继续持有价值的总体平均 MAE，B/C/D 分别为 0.015496/0.0003494/0.0001518；但低 MAE **没有**保证根拓扑正确。F-B 的 B/C/D 根数匹配为 58/66/65 条，T-B 为 56/53/41 条，每格分母 96。特别是 D 在 T-B 的价值 MAE 低于 C，却有更多根数失配；不能据价值误差宣称其边界更准确。最大已匹配单根误差 B/C/D 为 0.14577/0.002353/0.07668 短利率单位，均保留，不以平均掩盖异常。

因此，当前 16 训练组/格的状态条件模型**没有一种通过全部冻结测试曲线的真实边界门槛**；原 B 验证目标失败也与留出失败一致。C/D 的数值残差使价值拟合大幅优于 B，但其边界拓扑不稳定，且 C 仍负担 GTFK 在线数值计算。该结论是新的 16 训练组/格、16 测试组/格小样本研究，不外推为四格主价格盲测或 2048 组全分布边界认证。原 t=0 四格价格比较、原 23/32 边界资格失败和全分布导数未认证均保持原样。

原始数据、模型选择与逐曲线根值见 `outputs/conditional-boundary-test-v1/results/`、`outputs/conditional-boundary-fit-v2/results/`；部署、环境、节点 OS wait 与回传收据在对应阶段目录。
