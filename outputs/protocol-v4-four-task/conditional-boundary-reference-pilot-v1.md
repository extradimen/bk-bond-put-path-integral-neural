# 状态条件继续持有价值参考试跑 v1：事前冻结

现有 B/C/D 仅预测 t=0 价格，不能由其输出求行权日真实边界。新状态条件模型训练前，先验证继续持有价值标签与独立数值参考。本试跑沿用已在边界工作中观察过的 F-B 组 1、13 和 T-B 组 3、10，各取中间执行价，共 4/4 格-组；它们不是新的独立留出或方法比较。

对每组全部三个行权日，建立 PDE 倒推条件继续持有曲线，比较 1601 点/每年 200 步与 3201 点/每年 400 步两档；以精确 OU 转移加贴现分裂传播 3201 点/每年 400 步/24 阶独立复核。组内在事前规定的 33 个状态点上比较继续持有价值，两项最大绝对差各不超过 1e-4；三个行权日均需 PDE/OU 同为单根，根短利率差不超过 1e-4。最后行权日继续持有价值必须恰为零，价格递推必须不低于立即行权或继续持有价值。任一失败完整保留，不放宽门槛或提前训练。

数据与合约 SHA-256 固定；此前仅用合成常系数例做普通数学接口、退化恒等式与 PDE/OU 对照测试。证据运行须经项目部署器、全局 resources/preflight/experimentctl launch、不可变快照、同项目 SHA-256 物料及环境收据，结束以节点 OS child wait 和校验回传。试跑通过也只允许进一步开展训练数据质量/计时试跑，不构成网络边界精度结论。
