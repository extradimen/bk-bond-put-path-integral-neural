# 四格债券看跌期权比较：加入真实行权边界新模型的综合结算 v7

F-E、F-B、T-E、T-B 四格 t=0 定价主研究、每格 2048 正式测试组、五种子 4096 训练组预算，以及 E2–E6 补充分析均已完成，完整价格、成本、配对比较和原门槛见 `four-cell-final-synthesis-v6.md`。四格选定配置下 C 的平均价格 MAE 最低，B 计算最快但误差最大，C 的 GTFK 在线数值成本尤其在百慕大格很高。旧欧式看涨数据从未算入这四格看跌结果。

风险导数没有全分布认证，且不能把局部稳定误认作准确：T-B 组 120 的 A sigma1 导数与独立细 PDE 相差约 0.003217，而独立精确 OU 分裂与 PDE 仅差 4.77e-7；固定步距另 16 组中最大 A/PDE 差约 4.47e-4，后验三异常组的 OU/PDE 差至多 1.80e-7。粗 Dbase 与 D 的部分导数存在网格敏感性。原百慕大边界 23/32 资格门槛未通过；后验加密及域宽诊断解释若干失败，却不改写原失败。

为进行**真实行权日局部边界**比较，另开发状态与日期条件的 B/C/D 继续持有价值模型，而非重用只输出 t=0 价格的原网络。独立标签试跑 32/32 组通过；新训练/验证数据 40/40 组通过 1e-4 PDE/OU 标签门槛，数据 SHA-256 固定；每格用 16 train、4 val 组拟合 24 个候选并按验证 MAE 选六个模型。事前 0.002 验证目标下，C/D 两格通过，B 两格均失败。模型与收据见 `conditional-boundary-fit-result-v2.md`。

新的留出测试 F-B/T-B 各 16 组、三执行价、前两行权日，共 192 曲线。191 条独立参考通过事前数值资格，T-B 组 37 一条独立价值差 1.58e-4 而失格。按价值 MAE <=0.002、正确根数、短利率根差 <=0.001 的事前**联合**门槛，B/C/D 分别为 0/114/101 条通过。C/D 的价值平均 MAE 仅约 3.49e-4/1.52e-4，但根拓扑匹配率分别仅 119/192 与 106/192；价值拟合好并不保证行权边界正确。逐格、逐曲线记录及最大根差见 `conditional-boundary-test-result-v1.md`。这些是小样本新模型结果，不替代原四格 4096/2048 组价格主试验，也不是全分布边界认证。

所以当前证据可支持四格 t=0 价格的配置内排序和数值成本权衡，却不支持任何方法在全分布七坐标导数或真实百慕大边界上无条件通过。所有失败、参考未资格、部署权限失败、旧门槛及其原始收据均保留。后续若要求正面认证，需独立冻结更大状态条件训练预算、数值更细的行权日参考和全分布导数方案；不能事后调低本轮门槛。
