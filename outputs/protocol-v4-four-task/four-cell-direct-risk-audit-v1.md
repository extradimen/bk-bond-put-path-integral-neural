# Four-cell direct-network risk audit v1 (frozen before execution)

Use the first 128 certified test groups in each cell, middle strike only. The fixed F-E/F-B labels are the mixed-resolution repaired four-coordinate finite-difference PDE set; T-E/T-B labels are the merged mixed-resolution seven-coordinate set with explicit source provenance. Source files, SHA-256 hashes, seed list, coordinate order, sample count and exact model-selection rule are frozen in `configs/four-cell-direct-risk-audit-v1.json`. The selected price-only B network for each cell is the tuned 4096-group budget model for each of five predetermined seeds; no refitting, reselection or test-based calibration occurs.

Compute the analytic input gradient of each frozen MLP in the original transformed feature coordinates, applying the saved input and target standardization. Compare each coordinate to its matching PDE label using MAE, 95th percentile, maximum and sign-mismatch rate; also report subset price MAE. Preserve 20 cell-seed records. The four-coordinate and seven-coordinate spaces differ, so do not pool their coordinate means or claim a single four-cell derivative score. This is exploratory after the main price results were observed, with mixed-resolution labels and representative time/domain certification. It audits only direct B, not A/C/D derivative quality or the true exercise boundary.

Run via project immutable deployment, same-project SHA-256 material/environment receipts, global resources/preflight/experimentctl launch, node OS child wait and checksum-verified return. Any model identity or label alignment mismatch must fail and remain recorded.
