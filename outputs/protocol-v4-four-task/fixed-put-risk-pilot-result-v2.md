# 固定参数看跌风险导数预检阶段结果

v1 与 v2 均经全局控制器在不可变快照运行，节点 OS child wait return_code=0，结果以同项目 SHA-256 校验回传。v1 对训练前 8 组/格的 16 组中仅 5 组通过 1e-4 中心差分步长及 PDE 联合网格差门槛；v2 将网格由 401/200、801/400 加密为 801/400、1601/800 后，通过数增至 9/16。v2 最大步长差 `1.0830913849124713e-4`，最大联合网格差 `5.468900775894639e-4`；七组仍未过，分别为 F-E 2、4、5、6 和 F-B 0、2、6。

主要剩余问题是网格差，尤其 sigma 与 log(r0) 敏感度。两个网格联动变化尚无法确定是空间、时间、截断域还是折点/行权边界造成。不能将细网格半步的导数当作已认证标签，也不能据此启动 E3/E4 导数监督训练。后续应在失败组分别细化空间、时间和域，并检查移动状态网格与行权折点对中心差分的影响；保留两轮完整失败记录。
