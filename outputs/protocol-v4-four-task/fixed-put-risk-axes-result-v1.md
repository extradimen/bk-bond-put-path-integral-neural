# F-E/F-B 看跌风险导数失败组的独立轴诊断结果

`fixed-put-risk-axes-v1` 对先前未过门槛的七个训练参数组完成独立数值轴复核；校园节点 OS child wait return_code=0，全部结果 SHA-256 校验回传。每组四个坐标、三执行价的逐轴差异见 `outputs/fixed-put-risk-axes-v1/results/axes.jsonl`。

以 1601 空间点/每年 800 时间步、原域与原差分半步为基准，分别仅缩小差分步长、把空间加密至 3201 点、把时间加密至每年 1600 步、把截断域扩大 1.5 倍并保持近似空间步长。28 个组×坐标结果中，空间轴是 25 个的最大变化来源；差分步长轴是 3 个；时间和域均不是最大项。各轴跨全部合约/坐标的最大绝对导数变化分别为：差分步长 `8.670285008612749e-5`、空间 `2.77164331104196e-4`、时间 `2.313745028903469e-8`、域 `3.7594927171369363e-11`。

这明确将当前数值瓶颈定位于空间离散及在该网格上处理行权折点/移动初始状态，而非时间步或截断域；后半句的具体机制仍是推断，尚需进一步空间加密和折点专门诊断。不能将此阶段基准导数称为已认证标签，E3/E4 导数监督训练继续等待数值门槛。
