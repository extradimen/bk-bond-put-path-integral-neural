# 固定参数 E5：标签数值分辨率敏感性结果

`fixed-put-label-precision-v1` 经节点 OS child wait=0、SHA-256 校验回传。2048 组正式测试的组均 PDE 网格细化指标，F-E 平均 `1.0532e-8`（95 分位 `3.9505e-8`），F-B 平均 `2.4214e-8`（95 分位 `7.4927e-8`）。这说明原先 `1e-6` 是通过/失败门槛，不是典型标签变化量；先前把它笼统称作“参考分辨率约 1e-6”过于保守，应以这些实际指标补充解释。

F-E 中误差最小的 C 五种子平均 MAE 为 `2.5473e-7`，约为平均网格指标的 24.2 倍；F-B C 的 MAE 为 `2.1723e-6`，约为平均指标的 89.7 倍。两格的六个已冻结主要成对平均误差差均超过 `2 ×` 平均网格指标；其中最接近的是 F-B C 对 D，差约 `1.760e-6`，相当于这个启发式尺度的 36.4 倍。完整的逐方法及逐比较指标见 [summary.json](../../outputs/fixed-put-label-precision-v1/results/summary.json)。

网格细化指标不是对真实价格误差的严格上界，因此上述倍数**不能证明**实际排序一定不受标签误差影响，也不能替代先前的独立 OU 分裂检查或四格最终校正比较。它只表明，按这项已记录的网格变化代理衡量，固定参数测试上的主要平均误差差异不像是由典型网格变化量单独造成。
