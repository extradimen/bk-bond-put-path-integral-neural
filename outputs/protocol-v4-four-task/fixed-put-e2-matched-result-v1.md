# F-B 同误差级别 PDE 残差网络 E2 结果

`fixed-put-e2-matched-v1` 在 `campus-3090-2` 的不可变快照以 OS child wait return_code=0 完成，逐组基线、五种子拟合、测试评分及模型已按同项目 SHA-256 回传。该分析发生在原固定参数测试结果已查看之后，是探索性复核。

事先按验证前 128 组选中的 F-B PDE 网格为 101 点/每年 50 步。新 Dmatch 使用原训练前 1024 组、完整 1024 验证组、五种子，固定 3×64 网络和学习率 0.001；原 D 用相同预算、容量和种子的冻结模型。下表所有误差均来自相同 F-B 测试前 512 组、每组三执行价，相对同一高精度 PDE 数值参考。五种子网络值为各自 MAE 的平均，未做显著性声明。

| 方法 | 测试价格 MAE |
|---|---:|
| A：GTFK | 2.9968459169737096e-5 |
| 原 Dbase：201/100 PDE | 6.525682776224814e-6 |
| 原 D：201/100 PDE+网络，五种子均值 | 6.015847183795576e-6 |
| 匹配基线：101/50 PDE | 3.713203295530426e-5 |
| Dmatch：101/50 PDE+网络，五种子均值 | 3.411608768937289e-5 |

验证子集的 A MAE 为 `2.749263201925394e-5`，101/50 PDE 为 `3.505421737351119e-5`，所以该网格确是冻结规则在验证集的最近候选。但在上述测试子集，101/50 PDE 的误差高于 A；验证集的“误差匹配”未完全迁移。Dmatch 只把该测试 MAE 从 `3.7132e-5` 降至 `3.4116e-5`，仍高于原 201/100 D 的 `6.0158e-6`。这支持“数值起点精度对残差结果很重要”，不能单独证明 PDE 或 GTFK 方法族的普适优劣。

测试子集已经进入分析视野，后续对 101/50 的参数区域分析只用于解释边界，不能重新据此选网格再声称盲测。训练与多工作者基线生成耗时、模型归档及逐种子 95% 分位/最大误差保存在结果文件；这里的并发基线计时不是隔离在线耗时。
