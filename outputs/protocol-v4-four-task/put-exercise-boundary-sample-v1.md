# Actual exercise boundary sample v1 (frozen before execution)

After the two-group topology pilot, test the first 16 frozen test groups in each of F-B and T-B, taking the middle strike from the three-contract group: 32 cell-groups total. Source hashes and all five numerical settings are fixed in `configs/put-exercise-boundary-sample-v1.json`. This is an exploratory sample after price results have been observed, not a new confirmatory comparison.

At each early exercise date, define the boundary from the zeros of intrinsic value minus the continuation value of the remaining Bermudan claim. The final date is only a payoff kink, and must be reported separately. Record all roots and exercise-region node counts even when zero or multiple roots occur. For a group to qualify as a numerically stable single-boundary case, require exactly one early-date root in all five settings; for each early date, the maximum spread of the four PDE short-rate roots and the absolute difference of the independent OU-split root from the 1601-point/100-step PDE root must each be no greater than 1e-4. Report failures, missing roots and multiple roots without changing this rule or dropping groups. This tolerance assesses numerical boundary location in short-rate units; it is not a learned-model accuracy claim.

Use the project deployer on campus-3090-2 with the immutable source/data snapshot, same-project SHA-256 material and environment receipts, global resources/preflight/experimentctl launch, node OS child wait and verified return. The prior two-group pilot remains separately preserved. The sample result will determine whether larger boundary analysis is numerically meaningful.
