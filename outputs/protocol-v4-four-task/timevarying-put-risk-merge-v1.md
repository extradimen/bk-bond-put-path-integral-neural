# 时变看跌风险导数测试子集来源合并审计 v1 冻结

在 v1、v2、v3 三个数值阶段取得节点 OS child wait 和同项目 SHA-256 回传后冻结于 2026-10-23。输入逐组账本以配置中的 SHA-256 固定；目标为 T-E/T-B 各测试组 0–127 的中间执行价，共 256 格-组、每组七坐标。选择规则仅以原 v1 失败表为条件：252 个 v1 通过组保持原 6401 点细网格标签；原失败 T-E 52、76、100 使用已过门槛的 v2 9601 点标签；原失败 T-B 110 使用已过门槛的 v3 12801 点标签。v1/v2 的失败记录始终保留，不原地覆盖；不得任意选择较优价格或按模型效果挑标签。

合并运行须逐组检查身份、组号、执行价序号、七坐标、每项原 1e-4 数值门槛、原账本精确覆盖与四个失败的精确来源映射。输出逐组写来源阶段、空间点数、是否由 v1 失败加密修复。混合分辨率不可伪装为同一网格；时间/截断域仅代表性坐标检查。该 256 组标签只供已观察四格主价格结果后的探索性风险分析，非四格总体确认性检验。

单节点 CPU、至少 4 GiB、最长 15 分钟，固定 campus-3090-2。经项目部署器、不可变快照、同项目 SHA-256 物料与环境收据、全局 resources/preflight/experimentctl launch，节点 OS child wait 与 SHA-256 回传后才可使用合并结果。
