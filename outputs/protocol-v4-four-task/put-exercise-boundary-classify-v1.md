# Exploratory exercise-boundary topology classification v1

Frozen before running on 2026-10-24. Analyze the existing F-B/T-B middle-strike boundary sample, 16 test groups per cell, 32 groups total; use the eleven preselected refined scans where available. No prices, models, or numerical solvers are rerun. Only true early-exercise versus continuation dates are classified. Preserve the original 23/32 single-root qualification result unchanged.

The `gap_floor` is 5e-6, five times the earlier 1e-6 per-contract reference numerical gate, and the root-location tolerance remains the original 1e-4 in short-rate units. A positive minimum gap exceeding the floor is `all_exercise_on_grid`; a negative maximum below minus the floor is `all_continue_on_grid`. A gap too close to zero is `marginal_gap_unresolved`. A strong sign-changing gap with exactly one PDE root at both spatial resolutions and exactly one independent split root is `single_root_consistent` only if both root differences are within 1e-4. Otherwise the location or topology remains unresolved. The labels are post-observation exploratory classifications, not a revised confirmatory pass rate. Root absence may depend on finite grid domain; it does not prove global absence.
