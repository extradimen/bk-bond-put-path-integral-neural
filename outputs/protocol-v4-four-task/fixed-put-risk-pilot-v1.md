# 固定参数看跌风险导数标签预检 v1：运行前冻结

目标是先检验 F-E/F-B 对数回复速度 log(a)、波动率 sigma、对数初始利率 log(r0)、对数长期中枢 log(rbar) 四个局部价格导数能否取得可核验数值标签。执行价、行权日期和到期日固定；这些量不是股票 Delta/Vega。只用冻结训练集每格组 0–7、每组三执行价，不训练网络，不选择测试样本。

中心差分初始步长依次为 0.004、0.001、0.004、0.004，各自再减半；PDE 网格 401 点/每年 200 步和 801 点/每年 400 步。以细网格半步导数为暂定参考，记录与细网格全步（差分步长轴）、粗网格半步（空间与时间联合轴）的最大逐执行价差。两个轴均不超过 1e-4 方标记预检通过。联合轴通过只说明可进入独立空间、时间、域细化，不能称为导数标签正式认证。所有未过案例与逐坐标差异保留。

8 个 CPU 工作者，校园节点不可变快照、同项目 SHA-256 物料与环境收据、全局 resources/preflight/launch、节点 OS child wait 及校验回传均为证据条件。后续 E3/E4 是否启动须基于预检结果另冻结样本、独立轴门槛、训练预算和损失定义。
