# 时变看跌正式数据 v8：事前冻结的数值修复与新盲测集

2026-10-21。v6 正式数据 8192 组中 8191 组逐约认证通过，长到期域外第 396 组最低执行价因 T-B−T-E 低于 −1e-8 而失败，`summary.complete=false`。v7 对该已知失败组按事前冻结的 PDE 与独立 OU 两组网格作诊断，OS child wait return_code=0、同项目 SHA-256 校验回传。加密到 19201 点/每年 1280 步时，最低执行价 T-B−T-E 为 −2.06812022e-10；三轴 TE/TB 最大变化均低于 8e-10，独立 OU 细档给出 +6.20428e-12。原失败和诊断结果均保留。该诊断不是正式样本，也不能据此放宽 1e-8 支配容差或 1e-6 数值门槛。

原正式冻结协议要求修复后有完整新测试集。v8 因此不把 v6 的 2048 个测试组重新打包为新测试。保持总量 8192 和各划分组数 4096/1024/2048/512/512：train/val/ood_vol 沿用原种子 20261040/41/43，通过同项目 SHA-256 固定 v6 全部认证账本、节点 OS wait 身份及冻结 `sample` 合约，逐组复核后复用 4096/1024/512 组；test 2048 组改为事前未使用的种子 20261052，`ood_long` 512 组改为 20261054。新测试与新长合约域外集不得在拟合、门槛选择或修复期间查看结果。原 v6 的第 396 组不进入新 `ood_long`；它保留为诊断案例，不能计作 v8 的认证组。先前 v7 文字中“仅重算本失败组并复用其余 8191 组”属于诊断后的候选意向，本文件按原正式冻结协议更严格地替代该候选。

新组沿用 v6 已冻结的 PDE、GTFK A 和 Dbase 方法及 1e-6 独立轴门槛。若任一执行价出现 T-B−T-E<−1e-8，即对该价的 T-E 与 T-B **同时**按 v7 预先验证的 (19201,1280,1.0) 基档重算，并独立比较 (24001,1280,1.0)、(19201,2560,1.0)、(24001,1280,1.25)。两格各自三轴最大差必须≤1e-6，且以同一基档检查 T-B−T-E≥−1e-8；未过即留账停止。无触发价仍沿用原已认证参考档，绝不因模型误差或评价成绩选择档位。所有值有限、在 [0,K] 的原 1e-8 容差内，GTFK A 两档或回退差≤1e-6，均不得改变。对新的 test 和 ood_long 所有组逐项检查并留账；任何失败不发布完整数据，也不训练时变模型。
