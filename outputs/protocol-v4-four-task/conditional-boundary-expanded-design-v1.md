# 扩大状态条件模型与新留出边界：拟合前设计冻结

仅在 conditional-boundary-repair-v1 的全部失败组通过原 1e-4 独立标签资格、OS child wait 0、校验回传并得到新归档 SHA-256 后拟合。F-B/T-B 各 train 128、val 32 组，组级划分不变；只使用修复后的训练/验证归档，不读取测试划分。B 为直接继续持有价值网络，C 为 GTFK 条件残差网络，D 为粗 PDE 条件残差网络；相同编码、候选容量、随机种子、训练预算及按验证继续持有价值 MAE 选模。A/GTFK 与 Dbase 的在线成本须随后计入比较。

事前固定候选：每格每方法宽度 64/128/256、隐藏层数 2/3、随机种子 11/29、学习率 0.001，共 72 个拟合。每拟合最多 500 epoch、批量 256、验证早停 patience 40。按最小验证 MAE 选每格每方法一个模型，平手按文件名稳定打破；验证 MAE 目标保持 <=0.002。原 16/4 组、24 候选、B 验证失败及 192 条曲线测试失败均保留。新模型不是原 t=0 网络。

在拟合前固定新状态条件边界测试组：F-B/T-B 各取原 test 划分组号 128–191，共 128 格-组、三执行价、前两个行权日 768 条曲线；新状态条件模型未接触该 test。参考细 PDE 3201/400/1.0，与独立 OU 分裂 3201/400/1.0/24 阶逐曲线比较，价值最大差 <=1e-4、根拓扑一致且单根短利率差 <=1e-4 方有资格。B/C/D 各在 513 个内部状态的继续持有价值 MAE <=0.002、根数完全一致、单根短利率根差 <=0.001 才算通过。所有参考不合格曲线与方法失败保留在固定分母 768 中；分别报告价值 MAE、根拓扑、根误差、失败原因和在线数值成本，不将小样本既有 test 32–47 混入新测试。该检验仍属四格主测试之后追加探索性边界研究，不称全分布确认性认证。

拟合与测试配置将分别绑定当时已校验的数据/模型 SHA-256；全部证据仍经项目部署器、全局 resources/preflight/experimentctl launch、不可变快照、同项目物料及环境、节点 OS wait 和校验回传。
