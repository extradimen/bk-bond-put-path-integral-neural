# 风险导数七个失败组的独立数值轴诊断 v1

只检查风险导数预检 v2 中未过 1e-4 门槛的 F-E 训练组 2/4/5/6 与 F-B 训练组 0/2/6，仍固定各组三执行价和四个参数坐标，不读测试集或训练网络。中心差分基础步长沿用 v2 的半步：log(a)=0.002、sigma=0.0005、log(r0)=0.002、log(rbar)=0.002。

基准 PDE 为 1601 点/每年 800 步/原截断域；分别只改一个轴：差分步长再半、空间 3201 点、时间每年 1600 步、截断域 1.5 倍并用 2401 点近似维持空间步长。记录每组每坐标三执行价导数及四个轴相对基准的最大差，找出主要数值瓶颈。本阶段只定位误差来源，不能把基准导数作为正式标签。后续认证和 E3/E4 训练须另行冻结。使用同项目不可变快照、SHA-256 物料/环境、全局 preflight/launch、节点 OS wait 与校验回传。
