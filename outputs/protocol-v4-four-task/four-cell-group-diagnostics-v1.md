# 四格测试/域外组级诊断 v1 冻结

在运行前冻结于 2026-10-23。仅用四格已结束且 SHA-256 固定的正式数据、模型选择与盲测预测，不重新拟合或改变 24 项主比较。每格覆盖 test 2048、ood_vol 512、ood_long 512 组，共 4×3072=12288 格-组，每组三执行价。对 B/C/D 仅取 4096 组训练预算、验证选择配置、五个预定种子；逐组方法误差先平均三执行价绝对误差，再对五种子平均，与主分析口径相同。A/Dbase 为原数值基线。

逐组写出五方法价格误差、参考价格均值/最小值与低于 0.001 的执行价数量；按格/划分汇总 MAE、尾部分位、最大误差和含近零价格组的误差。固定与时变各自检查欧式/百慕大合约配对，并报告同输入组的提前行权价格溢价，计数低于 −1e-6 的异常、绝对溢价不超过 1e-5 的比例。溢价近零只是行权价值代理，不能冒称真实行权边界或风险导数；此分析为探索性诊断，不生成新的确认性 p 值。

所有输入文件的 SHA-256 由冻结配置逐项检查。单节点 CPU、至少 16 GiB 内存、最长 60 分钟，固定 campus-3090-2；通过项目部署器、不可变快照、同项目物料/环境、全局 resources/preflight/launch、节点 OS wait 和校验回传。逐组 JSONL 是中途进度账本，失败仍保留。
