# F-E/F-B 看跌正式数据修复：追加协议 v2

2026-10-18，在读取任何新看跌格验证、测试或域外标签之前冻结。`fixed-put-formal-data-v1` 已有节点 OS child wait return_code=0 与 SHA-256 校验回传，但其完整 4096 组训练账本中的第 3451 组、最低执行价，F-B GTFK 数值加密差为 1.0146178e-6，超出事前 1e-6 门槛约 1.46e-8。v1 因此 `complete=false`，没有生成训练用数据包或后续划分。旧账本、失败清单与全部收据保持不变。

只针对这个已暴露的训练合约所做的 `fixed-put-gtfk-failure-diagnose-v1` 已通过全局控制器、节点 OS wait 与校验回传。该约在 3201/4801 点、域宽 0.75 的 F-B GTFK 价格差约 1.291e-7；4801 点域宽 0.75/1.0 差约 5.295e-8。它支持加密数值网格后满足原 1e-6 门槛，而不是放宽门槛或改变经济模型。

v2 数据阶段读取 checksum 固定的 v1 训练账本 `a804440973153738a9440bdd100bc95154657dfe72d14dc34ee1140d69e1ef0a`，核对 4096 个组号、原样抽样合约与所有质量标记；4095 个已通过组保留原始结果，第 3451 组只重算最低执行价 F-B GTFK 的 3201/4801 点（域宽 0.75）及 4801 点（域宽 1.0），以 4801/0.75 价格为 A/C 共用基线，并要求两项差都≤1e-6。更正组与旧组、原始和新增设置、耗时及源 SHA 一同保留。若该约不通过，新阶段停机，仍不训练。其他训练标签不因这次失败而重算，也不把试跑数据加入。

对尚未生成的验证、测试、域外集统一采用相同的按需加密规则：先执行 v1 原规则；若仅 F-B GTFK 仍超出 1e-6，再计算 3201/4801 点域宽 0.75 与 4801 点域宽 1.0，并要求细档空间及域差均≤1e-6。PDE 参考、欧式 GTFK、价格界或其他检查失败时仍按原规则停止，保留失败组，不删样、不补抽。所有基线的自适应计算次数和完整在线耗时须在 A/C 成对报告。

为取得全新的未观察验证、测试和域外快照，v2 使用组数不变的新 RNG 种子：val 1024 组 `20261051`，test 2048 组 `20261052`，ood_vol 512 组 `20261053`，ood_long 512 组 `20261054`；train 仍为 v1 4096 组 `20261025`。组内三执行价及 F-E/F-B 成对。网络三档预算、五种子、八配置、十二项固定格主比较及四格 24 项 Holm 家族均不变。v2 最高 18 小时、24 单线程工作者、`campus-3090-2` 至少 32 GiB 内存；完整数据包和独立 OU 分裂传播交叉核验通过前不训练。所有运行仍经项目不可变快照、同项目 SHA-256 物料与环境、全局 resources/preflight/launch、节点 OS wait 和校验回传。
