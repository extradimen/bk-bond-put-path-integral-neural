For each three-strike group, average the existing PDE refinement indicator, which is the maximum change among recorded reference grid/time/domain settings. This is an exploratory post-primary sensitivity analysis. The refinement indicator is an observed grid change, not a rigorous bound on true PDE label error. Do not claim significance, exact ranking stability or an error ceiling from it.
