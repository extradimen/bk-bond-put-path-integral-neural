# 时变正式数据部署修订 v3：依赖中转

2026-10-18。v2 在 `campus-cpu` 完成同项目物料传送后，校园节点直接安装 hash-locked Python 依赖失败；控制器在任何正式数据生成前停止。用户针对本项目这一次依赖获取明确选择 **Mac 中转**。v3 仅在全局控制器的 `environment-build --fallback-relay mac` 中使用该选择；轮包进入本项目 Mac 内容寻址缓存并校验后离线传给 `campus-cpu`。不得推定为本项目以后任何获取的常设授权，也不复用其他项目命名空间。

v3 保留 v2 的 `campus-cpu`、24 工作者、48 小时预算，以及原冻结的全部样本、数值门槛、失败规则和统计比较。v1 的节点 CPU affinity 失败与 v2 的直接依赖失败均保留原始记录。v3 须使用新的不可变快照及项目物料、环境、全局启动和节点退出证据。
