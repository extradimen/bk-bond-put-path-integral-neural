# 未判定行权边界六组加密诊断 v1：事前冻结

原冻结 32 组中 23 组通过原单根资格门槛；追加拓扑规则仍有 F-B 1、2、6、13 与 T-B 3、10 六组的至少一个行权日不可判定。此诊断只复核这六组的中间执行价，不能修改原 23/32 结论，也不用于重新选择价格模型。

沿用既有 PDE 与独立 OU 分裂传播实现、相同合约和固定数据散列。新增 9601/12801 点空间、9601 点双倍时间、6401 点 24 阶独立分裂四档。逐行权日记录全部符号交叉、根位置、行权节点数、正内在价值节点数和 gap 极值。细网格根位置差 ≤1e-4 且独立传播根位置差 ≤1e-4 时才视为数值位置趋稳；若无交叉，仅报告在采样域内全行权或全继续，绝不推断全域无边界。根数不一致、近切触或其他情形留作未判定。独立传播与 PDE 的实现差及近切触极小 gap 不因价格接近而抹去。

冻结总量为 6/6 格-组，属已观察失败后的探索性诊断，不是网络在行权日状态的局部边界误差测量。节点运行通过项目部署器、全局资源预检与实验控制器，保留不可变快照、同项目 SHA-256 输入和环境收据、OS wait 与校验回传。
