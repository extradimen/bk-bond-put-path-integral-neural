# 细网格风险导数独立轴与新组预检 v2：运行前冻结

单独空间加密 v3 在开发中已用训练组 0–7/格，全部通过 1e-4 门槛。为避免只验证被反复检查的组，本次各加入此前未用于导数开发的训练组 8、9，并保留各格两组较困难旧案例：F-E 2、4；F-B 0、6。总计 8 组、各组三执行价、四参数坐标。所有合约价格标签仍来自原 SHA-256 固定数据包，本次只求数值导数，不训练网络。

以 6401 空间点/每年 800 时间步/原域、初始差分步长的半步为基准，独立比较再半步、12801 空间点、每年 1600 时间步、1.5 倍域且 9601 点保持近似空间步长。每组/坐标逐执行价记录四轴最大差，全部轴均须不超过 1e-4 才视为代表预检通过；失败不剔除。即使通过，正式 256/128/128 风险标签仍需逐组认证及另行冻结网络训练计划。旧失败与诊断保持完整。部署与证据条件同全局协议。
