# 固定参数看跌导数单独空间加密结果

`fixed-put-risk-pilot-v3` 在相同训练前 8 组/格、各组三执行价与四参数坐标下，将空间网格从 3201 加密到 6401 点，时间保持每年 800 步。节点 OS child wait return_code=0，同项目 SHA-256 回传完成。16/16 组通过冻结的 1e-4 两类门槛，最大差分步长变化 `2.8877575164891478e-5`，最大空间网格变化 `5.8244893776093765e-5`。先前 v1 的 5/16、v2 的 9/16 失败保留，说明此前风险导数瓶颈确实可由单独空间加密显著缓解。

这不是正式导数标签认证：时间/域独立轴此前只在 1601 点基准检查；6401 点需要复核这些轴。还需检查未参与网格修复的训练新组，并在正式标签阶段保留逐组失败而非删除。未通过这些门槛前，E3/E4 导数监督训练不启动。
