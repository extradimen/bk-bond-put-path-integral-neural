# 固定参数看跌导数的单独空间加密 v3

独立轴诊断显示七个失败组的最大导数差来自空间网格，时间和域变化均低于 1e-7。为判断空间加密是否使既定 1e-4 门槛通过，v3 对相同训练前 8 组/格、相同三执行价和四坐标重新计算中心差分，空间点数 3201→6401，时间保持每年 800 步，原截断域不变。每个坐标仍比较初始差分步长与半步，门槛仍为两类最大逐执行价差均不超过 1e-4。全部 16 组重算，不选择性删除旧失败组。

v3 只是单轴空间收敛预检，即使通过仍须核查独立时间和域精度、不同未参与修复的样本，方可冻结 E3/E4 正式导数标签与训练。旧 v1/v2 的失败与轴诊断均保持完整。运行需通过项目不可变部署、同项目 SHA-256 物料/环境、全局 resources/preflight/launch、节点 OS wait 与校验回传。
